# AI安全应用场景

下列内容是结合公开方法对实际业务的设计建议。

SLG指标口径/数据库权限、AI短剧资产血缘/权利复审，以及机审人审的具体接口与验收条件，见[生产接入路线](production-integration.md)。该路线尚未接入真实业务。

| SLG/AI短剧数据库Agent | 指标口径、库表ACL、只读SQL、行数限制、导出授权 | 正确取数率、跨租户查询、错误口径、导出事件 |
| AI审核工作台 | 模型建议、证据定位、专家队列、申诉独立复核 | 漏放曝光、误杀、复核时长、翻案 |

| 广告素材与投放 | 广告主资质、素材落地页快照、预算及投放批准 | 误驳、违规消耗、上线周期、预算越权 |

| 政策问答与资格条件核验 | 规则覆盖、地区/时间变量、真实凭据与补证 | 逻辑矛盾、失效证明、正常任务完成、复核率 |

## SLG数据库Agent：把回答安全和取数权限分开

用户请求某服付费留存，先确定指标口径、服务器范围和时间窗。SQL只读、数据库身份、表/列/行权限与查询预算在数据库或网关层执行。模型回答应给出来源和口径；原始用户明细导出单独授权。对黑产名单的处罚建议与实际封禁接口分开，审核员批准后执行。

## AI短剧/漫剧：素材与结果的双重治理

剧本、分镜、生成图像、语音、成片和营销素材共享资产血缘。内容风险、素材权利、人物授权和AIGC标识分别存证。剧情安全不能证明版权合规；标识完整也不能证明内容真实。对外发布与模型生成采用不同门禁。

截帧检测只覆盖采样画面，音轨、字幕与跨帧语义单独登记；模态缺失不能填成安全。高影响内容或权利争议转专家。审核改判后逐路径核验播放和分发状态，保留部分失败与误判恢复记录。参考[腾讯截帧边界](../cases/video-frame-freeze.md)、[阿里云已有URL边界](../cases/vod-review-revocation.md)，二者产品行为不同，不可互相外推。

## 审核中台：三类队列

高置信、低影响内容可自动处理并随机抽检；不确定或多模型冲突进入人工；高影响处罚进入专家复核。自动通过和自动拦截双向抽检，申诉复核与原审核员隔离。审核员纠错经过政策版本、证据和标注质量检查后进入训练集。

模型整理证据、审核员裁决、独立服务批准、执行器处置分别留痕。可采用轻量筛查 → 强模型/人审升级，但同时计算一级漏放、正常误升级、最终质量和总成本；[级联审核方法](../methodology/context-and-cascade-review.md)不是已部署能力。

## SLG资格与处罚：规则一致还要证据真实

充值活动、返利资格、客服补偿和名单处罚涉及对象、区服、活动期与政策版本。逻辑校验可检查陈述是否符合已建模条件，但数据库事实、凭据有效性和操作者权限另行验证；用户提供的截图或模型解释不能自行成为授权。见[AWS政策核验Case](../cases/automated-reasoning.md)。

## 平台滥用：看授权范围和实际动作

连续任务、工具回执与目标范围可以帮助安全调查，不能仅凭某条普通开发请求自动处罚。验证合法开发对照，控制日志原文、租户隔离和证据访问；高影响处置由专家与批准服务完成。[Anthropic披露解析](../cases/agentic-cyber-abuse.md)是厂商报告学习，不是本项目已发现的攻击。

以上新场景对应E17—E22待执行设计，现有离线控制套件没有验证模型分类、媒资撤销或完整业务服务。统一落地关系见[证据到处置闭环](../methodology/evidence-to-enforcement.md)。
