# AI审核与人工审核的业务整合

以下是设计方案，没有宣称已实现队列服务或大厂内部系统。

[生产接入与验收](production-integration.md)进一步拆解租约领取、迟到提交、独立申诉、恢复回执和质量/成本分账；目前仍是待实施设计。

## 四类入口

1. 自动通过：低影响且满足政策；持续随机抽检估算漏放。
2. 自动限制：证据充分、可恢复处置；持续抽检估算误杀。
3. 人工疑难：低置信、多模态冲突、缺资质、跨政策判断，分配有相应技能的审核组。
4. 专家与申诉：高影响处罚、重大争议和已处置申诉；与原审核人隔离。

模型置信度不是校准后的错误概率；队列分流阈值先由留出集与业务风险确定。封号、断播、资金等处置单独授权，不由分类器直接执行。

## 统一工单字段

case_id、业务对象及版本、租户、地区/语种、政策版本、模型版本、风险标签、证据位置与权限、机审建议、人工结论、理由码、处置回执、时限、申诉关联、抽样概率、最终专家标签。内容修改后生成新版本，避免旧审核结果套到新素材。

## 状态与责任

新建 → 排队 → 分配 → 判断 → 处置待批准 → 执行 → 结案；申诉生成关联复核单，可恢复并重新评测。超时进入升级/受限状态，不自动转为通过。安全策略维护政策，算法维护检测，审核运营负责队列与QA，产品负责处置体验，工程负责执行和审计，法务处理适用要求。

## 人审质量

盲审重复样本、多审一致性、专家锚点、错判分级。不能仅以件/小时考核审核员；同时看错误严重度、证据完整、有效处理时长和申诉复核。申诉翻案率只能代表已申诉结案人群，不能当总体误杀率。

## 数据闭环

机审与人审冲突 → 专家复核 → 对象去重 → 政策版本确定 → 训练/调优/留出拆分 → 影子差异 → 批准发布。只把有可靠标签的样本送进训练，保留分歧和原始证据；不让线上反馈直接自动改阈值。

## SLG、短剧与商业审核

SLG名单封禁须结合行为证据、正常大R/联盟行为对照、人工复核和恢复接口。AI短剧联审剧本、画面、音频、人物授权、素材权利与标识；剧情安全与素材权利不可互相替代。商业化审核结合商品/广告主资质、素材和落地页版本，先给整改建议，再对高影响处置复核。

## 降本验收

对照同风险底线的方案；观察单位正确结案成本、重复提交、人审时间、漏放曝光、误杀损失和申诉负担。释放审核产能与兑现现金节约分开报告；记录前置纠错是否只是把成本转给商家或用户。
