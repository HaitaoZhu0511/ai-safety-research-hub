# 90天实施路线与岗位能力

## 0—30天：建立基线

盘点业务场景、资产、权限、工具和数据流。统一风险标签、事件协议与政策版本，抽样分析真实失败、误杀和成本。选择一个低范围试点，例如数据Agent的只读聚合取数或审核员证据助手。

交付：风险登记表、权限矩阵、事件Schema、Golden Set初版、业务与安全成本基线、试点范围。

## 31—60天：闭环试点

接入输入、检索、工具边界和输出检查。串联人审与申诉；候选策略影子运行，分析新增拦截和正常完成损失。评测集与调优集隔离，生成有来源和版本的报告。

交付：可回放Trace、16类设计用例的业务适配、人工队列、样本准入、影子差异、灰度/回滚配置。

## 61—90天：验证收益并推广

灰度扩大范围，观察安全、正常完成、成本、人审、时延和业务效果。事故演练，验证工具权限和Kill Switch。只有可量化收益与剩余风险都被解释后才扩大业务接入。

交付：试点验收报告、现金/产能收益分拆、质量趋势、残余风险、下一阶段路线。
