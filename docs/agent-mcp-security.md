# Agent与MCP执行安全

## 官方能力与本项目建议

[OpenAI MCP官方文档](https://developers.openai.com/api/docs/guides/tools-connectors-mcp)描述可见工具限制、敏感动作批准以及第三方服务的数据风险。允许模型发现工具与允许用户实际执行是两道不同控制。以下绑定与幂等机制是本项目建议和离线实现，不是SDK自动承诺。

## 资产登记

每个连接登记运营方、域名、数据分类、调用身份、可见工具、工具Schema、只读/写入/外发性质、预算、许可证和停用负责人。工具描述或返回文本是不可信输入，不能决定自身权限。只读标签是提示，不是授权证明。

## 执行前校验

调用者、租户、工具、目标、金额/行数、目的地、任务范围、政策版本全部在可信服务检查。数据库查询与摘要外发分别授权；不因用户拥有某文档权限就允许将它发送给任意服务器。外部文本中包含批准语句不能作为审批结果。

## 审批与状态

提案 → 校验 → 待批准 → 独立审查 → 校验快照/到期/当前权限 → 执行 → 回执。

批准绑定规范化参数和完整政策快照，变化则重新审查。生产审批必须校验审查者身份与租户；拒绝、撤销、超时均不能执行。动作失败需要明确“未执行、已执行、结果未知”状态，不能在结果未知时无条件重试。

## 幂等与故障

使用租户/用户/动作ID及参数摘要，事务性保存执行状态和回执。同ID不同参数拒绝。敏感动作的权限服务故障时拒绝执行。只读低影响任务可按批准策略受限降级，不能用统一fail-open绕过授权。

## 供应链与出站

优先官方服务；锁定部署版本与Schema摘要，变化触发复核；限制目标域与网络、重定向和资源加载。日志默认存引用和摘要，原始正文按分类、权限和留存期另存。第三方数据保留策略需单独核验。

## 验证

[离线演示](offline-demo.md)可验证参数绑定、到期、当前政策和重复执行，但没有接入MCP服务器。真实接入前还需OAuth/令牌范围、服务端授权、取消与重试、并发、网络出站和多轮模型评测。
