# 评测、指标和发布门禁

## 先分清验证性质

本项目的16个[脱敏Case](../evals/design-cases.json)是验证设计；`scripts/validate.py`只校验资料结构。当前没有实测模型、没有在线攻击、没有厂商防护排行榜。

v0.3运行24个[确定性控制用例](../evals/control-golden.json)，见[结果报告](../reports/README.md)。它们输入固定合成工具提案，验证权限、批准与实际事件标签，不是原16个模型设计的执行结果。66项单元测试另检查同实例线程并发、审批人追溯、事件契约、参数变更、审计链、收益算例和报告一致性。

顶层risk_ids表示测试设计的覆盖面，expected.risk_ids/observed.risk_ids表示最后一条实际事件的期望与观测标签。不能据覆盖prompt-injection或grounding的用例，宣称已测自然语言注入检出或回答真实性。并发、重启限制测试属于单元测试，不混入24个顺序控制用例的分母。见[修复说明](control-hardening.md)。

真实评测需要：目标应用与工具版本、政策、模型、测试范围、数据集版本、运行次数、人工基准、预算与评测日期。

## 指标口径

| 指标 | 分子/分母 | 注意事项 |
| --- | --- | --- |
| 风险召回 | 正确识别的真实风险 / 全部真实风险 | 需有独立标签 |
| 精准率 | 正确识别的风险 / 全部风险判定 | 不能代替召回 |
| 正常误拦 | 被阻断的正常请求 / 全部正常请求 | 与拒绝原因分开统计 |
| 攻击成功 | 达到预定危险结果的尝试 / 有效攻击尝试 | 记录预算与重试；最终文本拒绝不等于工具未执行 |
| 正常完成 | 正确完成的授权任务 / 全部授权任务 | 检查结果和副作用 |
| 人审翻案 | 撤销原决定的有效申诉 / 有效已结申诉 | 申诉用户有选择偏差，不能当总体误杀率 |
| 风险曝光 | 违规曝光 / 总曝光 | 抽样估计需权重与置信区间 |
| 单位完成成本 | 推理+检测+人审+重试成本 / 正确完成任务 | 避免只看一次调用成本 |
| 证据完整 | 必需字段齐全事件 / 应留证事件 | 不能证明证据语义正确 |

## 数据集

风险正样本、正常近邻样本、长上下文、多轮、图文、不同语言、工具与检索、已修复Case分别切片。训练/调优/评测按对象或风险簇去重切分，防止同一内容变体穿越集合。

抽检自动通过样本估算漏放，抽检自动拦截样本估算误殺。重点风险过采样后的结果需按真实生产分布加权；均衡测试集的准确率不能直接解释生产效果。

## 模型裁判

模型裁判帮助扩大评测规模，但需专家标注锚点、盲审、多裁判一致性和失败复核。裁判版本与提示均留存，裁判看不到自己评价将影响哪些业务利益，降低动机性标签偏移。

## 发布门禁建议

必须通过权限隔离、敏感外发、审批绕过、严重风险回归与正常任务对照。阈值从业务基线和影响等级定义，不能为所有场景设置一个通用百分比。首次上线先影子、再灰度，绑定负责人和回滚版本。
