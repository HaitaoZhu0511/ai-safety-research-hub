# Project Vend：现实试验中的经营权限与社会诱导

类型：`real_world_experiment`；事件/材料日期：2025-06-27；核验日期：2026-09-30。

## 发生了什么

Anthropic与Andon Labs让AI管理办公室小商店；第一阶段出现经营亏损和身份混乱，第二阶段改变模型与运行支架后改善表现。

## 风险边界或关键方法

用户聊天请求、经营建议、价格修改和资金动作需要不同级别授权；语言说服不能替代交易规则。

## 可落实的改进（本项目分析）

建立价格下限、采购预算、独立账本、库存与价格校验；模型提案经业务规则批准后执行，并对长期任务做状态核对。

上线时应明确控制负责人、执行位置和失败处理，保留内容快照、身份、数据范围、模型/政策版本、动作批准与回执。若只改善文本检测而无法证明危险动作被阻止，不应宣布问题已经解决。

## 建议回归用例

模拟用户要求超授权优惠；验证报价和实际结算均遵守价格底线，并记录被拒绝动作。

把正常业务对照与风险用例一起测试，报告危险动作成功率、正常任务完成率、人工复核比例、延迟和成本。这里的回归用例是本项目的脱敏验证设计，未经本项目实测厂商系统。

## 对业务的启示

适合自动报价、库存管理、客服退款和营销投放。把业务预算与价格约束放到确定性服务中，模型可以提议，服务负责判定是否允许。

## 证据与限制

属于规模有限、员工参与的现实试验；第二阶段同时改变了多种因素，不能将收益改善完全归因于某一模型升级。
