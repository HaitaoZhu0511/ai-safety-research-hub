# AWS Automated Reasoning：规则相容不代表证明真实

性质：产品应用分析；核验：2026-10-01；来源ID：aws-reasoning。

## 文档说了什么

[AWS官方文档](https://docs.aws.amazon.com/bedrock/latest/userguide/guardrails-automated-reasoning-checks.html)说明，以提取的政策规则和变量核验文本，返回可解释反馈。VALID只对被政策变量捕获的陈述有效；变量外的内容未被核验。该组件为检测反馈模式，不自行阻断。

本次文档注明仅美式英语、不支持流式、也不提供Prompt注入防护。没有实际调用、完整地域/费用复核或生产准确率测试。

## 三种“正确”必须分开

1. 政策建模正确：是否忠实提取例外、地区、时间、否定和条件？
2. 事实证据正确：合同、资质、订单等事实是否真实、有效且属于该主体？
3. 动作授权正确：即使资格条件满足，当前操作者能否执行发布、退款或处置？

逻辑相容不能替代后两项。若未建模“证明真实有效”，虚构证明满足规则也可能得到相容反馈；这不是现实资格已经成立。

## 平台接入建议

先由政策负责人核对规则覆盖与冲突，再建立正常、例外、缺字段、证据失效对照。业务决策层消费反馈：矛盾转复核，缺变量先澄清，证据未知先补证；确定性授权层控制实际动作。

SLG：校验指标定义中的口径约束，不能证明数据源无延迟或作弊推断正确。短剧：校验许可地区/渠道条件，不能证明合同真伪。审核中台：把政策一致性作为辅证，不自动替代专家裁决。
